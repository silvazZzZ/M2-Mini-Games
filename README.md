# Trabalho M2 — Jogos em C++

Projeto desenvolvido em C++ com um menu interativo contendo dois jogos executados no terminal.

## Funcionalidades

### 🎲 1. Jogo da Adivinhação

O jogador deve descobrir um número aleatório entre `-100` e `100`.

O sistema fornece dicas progressivas conforme o número de tentativas:

* Dica de par ou ímpar após 5 tentativas;
* Sistema de “quente” ou “frio” a partir da 7ª tentativa;
* Dica se o número é positivo ou negativo a partir da 10ª tentativa;
* Informação da distância entre o palpite anterior e o número secreto a partir da 12ª tentativa;
* Regras adicionais criativas para tornar a experiência mais dinâmica.

### 🧠 2. Quiz de Conhecimentos Gerais

Quiz com perguntas de múltipla escolha sobre temas variados, como:

* Geografia
* História
* Ciências
* Conhecimentos gerais

O sistema informa se cada resposta está correta ou incorreta.

### 3. Menu Interativo

O programa apresenta um menu com as opções:

```text
1. Jogo da Adivinhação
2. Quiz de Conhecimentos Gerais
3. Sair
```

O usuário permanece no sistema até selecionar a opção de saída.

## Tecnologias Utilizadas

* C++
* Estruturas condicionais
* Loops de repetição
* Geração de números aleatórios
* Entrada e saída de dados no terminal
